Focus Area

Windows Server & Systems

Keeping the servers, directory, and endpoints that a campus runs on actually running.

As an IT Support Tech (Work Study) in Tacoma Community College's IT Department since 2024, I get hands-on daily with Windows Server and Active Directory — troubleshooting hardware, software, and account issues across campus systems for faculty, staff, and students. It's real production infrastructure, not a sandbox, which means every fix has to hold up.

Before that, I built the foundation for this work as a Help Desk Technician at TCC's Information Commons, handling front-line device and software troubleshooting, printing issues, and general tech support for the campus community.

Automation & Efficiency

I built an IT Onboarding Automation tool — a PowerShell script suite that automates new-hire account creation across Active Directory, Microsoft 365, and ServiceNow. It cut onboarding time from roughly 2 hours down to under 10 minutes, which matters a lot when you're processing accounts for a campus-sized population. That project is a good example of how I approach systems work: fix it once, then automate it so it doesn't need fixing by hand again.

I also work across Linux and macOS environments and manage Group Policy configurations, so my systems experience isn't limited to one platform.
